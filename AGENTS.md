## Cursor Cloud specific instructions

This is a minimal Python repository containing a single script (`example.py`). There are no frameworks, databases, package managers, or build systems.

**Running the application:**
```
python3 example.py
```

**Key notes:**
- Python 3 is the only runtime dependency. The VM has `python3` available at `/usr/bin/python3`; the bare `python` alias may not exist.
- There are no tests, linters, or build steps configured in the repository.
- There are no external dependencies or `requirements.txt`.
